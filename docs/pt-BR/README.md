# Documentação do Kerosene Contracts

Este repositório é a fonte única dos protocolos compartilhados entre os
serviços e clientes da Kerosene.

## Responsabilidade

- schemas versionados;
- tipos de protocolo compartilhados;
- regras de compatibilidade;
- vetores de teste;
- regras de identificadores, timestamps e assinaturas.

A documentação de endpoints específicos continua no repositório do serviço que
implementa a API.
